# Kaggle Machine Learning Projects

This repository contains three independent data-analysis and machine-learning projects. Each project has its own dataset, notebook, and README with project-specific details and setup instructions.

## Projects

- [Bike Store Sales Relationships](Bike-Store-Sales-Relation/README.md): explores bike-store product, customer, order, store, staff, and inventory data, including CSV consolidation and SQLite queries.
- [BMW Global Sales Prediction](BMW-Global-Sales-Prediction/README.md): explores monthly BMW sales by model and region alongside pricing and market indicators.
- [Digit Recognizer](Digit-Recognizer/README.md): trains a small NumPy neural network to classify 28 x 28 handwritten digit images.

## Getting started

Open a project folder and follow its README for the notebook to run and the required packages. The projects use separate environments and datasets; dependencies are not managed by a shared requirements file.
